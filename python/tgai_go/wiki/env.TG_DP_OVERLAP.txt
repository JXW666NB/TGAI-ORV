[ID] env:TG_DP_OVERLAP
[分类] distributed
[中文名] 反向即归约（默认关）
[英文名] Overlap reduce with backward (off by default)
[作者] JXW

=== 中文 ===
控制"归约与反向重叠"。**从 1.0.16 起默认关闭**，只有显式 `TG_DP_OVERLAP=1` 才开。

为什么默认关：2026-11-21 在 2×4090 上实测发现，`host` 后端的重叠传输**后台线程一个桶都没处理**，
却报 `comm=0.00ms / pending_zeroed=True` —— 看起来完全正常，实际**梯度根本没被归约**，
数据并行静默退化成"各卡各训"（loss 照样下降，极难发现）。现在该路径会明确报不可用并退回正确路径。

⚠️ `TG_DP_BACKEND=nccl` 时重叠路径**确实在通信**（实测 comm=420ms），两个 rank 也逐位一致，
但它的 gnorm 与不重叠路径差 10.3%，**等价性尚未证明** ⇒ 仍然不要用于正式训练。

=== English ===
Controls "reduce gradient while backward runs". **Off by default since 1.0.16**;
only `TG_DP_OVERLAP=1` enables it.

Why: measured on 2x4090 (2026-11-21), the host-backend overlap transport processed
ZERO buckets yet reported `comm=0.00ms / pending_zeroed=True` -- gradients were never
reduced and data parallelism silently became "each rank trains alone" (loss still fell).
That path now raises and falls back to the correct one.

⚠️ With `TG_DP_BACKEND=nccl` the overlap path does communicate (comm=420ms measured) and
both ranks agree, but its gnorm differs from the non-overlap path by 10.3%, so
equivalence is NOT proven -- do not use it for real training yet.

=== 示例 ===
TG_DP_OVERLAP=0 python -m tgai_go.train.v3_pretrain ...   # 默认，正确
TG_DP_OVERLAP=1 TG_DP_BACKEND=nccl python ...             # 实验用，别用于正式训练
