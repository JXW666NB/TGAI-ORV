## 五、代价与仍欠的部分

* **时间**：16384 上 0.185 s → 0.232 s（约 +25%，来自反向重算注意力）；
  8192 上 0.053 → 0.085 s。属预期的"用算力换显存"。
* **内核数随 seq 增长**（1116 → 1692 → 2844 → 5148）：分块在 Python 里循环，
  每块若干个 kernel。
* **阶数仍 1.22~1.36，未达目标 ≤1.15**：剩下的是 **掩码**仍是 `B·T·Tc·4` 的整块
  （32K 时 1.07 GB、64K 时 4.3 GB）。要彻底线性化，需要把掩码也惰性化
  （`_mask_global_fixed` 只是 chunk 粒度因果，可在内核里按需判定）。
