# 超长上下文：两边增长阶曲线 + ORV 的根因定位（2026-11-17 实测）

> 超小模型（d=128 / 2 层 / d_ff=256 / vocab=8192 / n_q=4），这样显存不成为干扰，
> 能一路把 seq 推到 64K，看清**渐近阶**。

## 一、ORV 曲线（超小模型）

| seq | 步时 | tok/s | 峰值 | 其中激活 | 时间阶 p | **显存阶 p** |
|---:|---:|---:|---:|---:|---:|---:|
| 512 | 0.021 s | 24,610 | 0.11 GiB | 0.10 | — | — |
| 2048 | 0.022 s | 94,682 | 0.43 | 0.42 | 0.03 | **1.04** |
| 8192 | 0.053 s | 155,156 | 3.41 | 3.40 | 0.64 | **1.51** |
| 16384 | 0.185 s | 88,399 | **11.98** | 11.97 | **1.81** | **1.81** |
| 32768 | **❌ OOM** | | | | | |

## 三、对比与交叉点

| seq | ORV | PyTorch | 谁快 |
|---:|---:|---:|---|
| 512 | **0.021 s** | 0.030 s | ORV 1.43× |
| 8192 | **0.053 s** | 0.060 s | ORV 1.13× |
| 16384 | 0.185 s | **0.160 s** | **PyT 1.16×** |
| 32768 | ❌ OOM | **0.450 s** | PyT 胜（ORV 跑不了）|
| 65536 | ❌ | **1.44 s** | PyT 胜 |

**交叉点 ≈ seq 12K～16K**，与 1.5B 上的外推（≈12K）一致。
两者时间阶都趋向 2（注意力的 FLOPs 本来就是 O(seq²)），但：

* **PyTorch 的显存是 O(seq)**（flash/SDPA 从不物化 score 矩阵）⇒ 64K 能跑
* **ORV 的显存是 O(seq²)**（实测 p→1.81）⇒ 32K 就 OOM

## 四、根因定位（已查到底）

| 位置 | 代码 | 是否物化 |
|---|---|---|
| `v3_pretrain.py:781` | `attn = C.csa_forward(xn, L["csa"], plan, cos, sin)` | **CSA 层走这条** |
| `v3_csa.py:765` | `scores = (q @ k.swap_last2()) * scale` | **✅ 物化 `(B,H,Lq,Lk)`** |
| `v3_pretrain.py:783` | `V.attention_orv(...)`（全局层）| 内部走 `v3_flash_op.flash_attn` |

**关键发现：ORV 里本来就有 flash 实现，但 CSA 层没用它。**

* `v3_flash_op.py:170` `flash_attn(q, k, v, causal, cq, ck)` ——
  注释记录"八组 `(causal,cq,ck)` 组合误差 1e-9~1e-8"，**数值已验证**
* `v3_ops.py:421-422` 与 `v3_train_cli.py:524-525` 已经在调它
* `v3_attn_chunked.py` 开头就写明："物化路径的峰值来自 `scores = q·kᵀ`，
  形状 `B·H·S·S`，`S²` 直接进显存"

⇒ **不是要重写 flash，是要把 CSA 的全局分支接到已有的 flash/chunked 上。**

## 五、下一步（明确的工程项）

1. 把 `csa_forward` 的全局分支从"物化 scores + softmax + 加权"改成
   `v3_flash_op.flash_attn`（或 `v3_attn_chunked` 的分块版本）。
   注意 CSA 的全局分支**跨 chunk 池化后的 kv**（`Lk = T/c`），形状不同，需要按它的
   `cq/ck` 参数适配。
2. 验收：①`faithful_parity` 误差仍 ≤1e-5；②16K 峰值应从 11.98 GiB 降到 O(seq) 量级；
   ③814 passed。
3. 预期：ORV 能跑到 **32K/64K**，且在那里的时间优势回到 PyTorch 之上
   （因为我们还有 CPU 侧优势，而 flash 让两边注意力都变成 O(seq²) FLOPs / O(seq) 显存）。
