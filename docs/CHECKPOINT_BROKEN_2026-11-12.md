# 检查点失效：实测与定位（2026-11-12）

> **结论先行**：`T.checkpoint` **当前不释放层内激活**。前向峰值随层数**线性增长**，
> 与关闭检查点几乎一致（还多约 0.1 GiB/层）。这是 P100 16GB 无法训练的**首要原因**。

## 1. 决定性实测

配置：D=1280 / NH=10 / **dh=128** / FF=5120 / S=2048 / B=1，只改层数 L。
指标：`pool_stats()["peak_live_bytes"]` 减去基线（只算活张量，不含池缓存）。

| 层数 L | 检查点**关**（前向峰值）| 检查点**开**（前向峰值）|
| --- | --- | --- |
| 2 | 1.56 GiB | 2.09 GiB |
| 4 | 3.09 GiB | 3.83 GiB |
| 8 | 6.17 GiB | **7.30 GiB** |

**判读**：

- 关闭时线性增长（≈0.78 GiB/层）= 预期，所有层激活同时驻留。
- **开启时也线性增长（≈0.87 GiB/层）**，且比关闭**更高** ⇒ 检查点等于没开，
  额外开销来自它保留的段输出。

**检查点若真生效，前向峰值应几乎与 L 无关**（只多出残差流的线性部分，量级 21 MB/层）。

## 2. 与之相印证的用户实测

P100 16GB，20 层 / d=1280 / FF=5120 / 10 头（dh=128）/ B=2 / S=2048 / 开检查点：

- 用户实测：ORV 活张量 **15.15 GiB** ⇒ 16 GB 卡 OOM；torch fp16 同形状 8.99 GB。
- 本次在 V100 32GB 上复现同配置（0.9.52）：**31.29 GiB 时 OOM**（参数 606M，比他的 434M 大）。

两者都远高于"检查点生效"应有的水平。按 434M 参数算，参数+梯度+AdamW≈6.4 GiB，
激活若只留一层应≈1 GiB，**总约 7.4 GiB**；实测 15 GiB ⇒ 多出的 8 GiB 就是没释放的 20 层激活。

## 3. 已排除与待查

**已做过的修复（0.9.51）**：`checkpoint` 里把输出张量的 `_parents` 清空、去掉输出克隆。
当时在 dense 小模型（6 层 / d=512 / S=512）上测到 0.857→0.602 GiB（−30%），
但那个规模下单层激活只有几 MB，**看不出问题**。本次用 S=2048 / dh=128 才暴露。

**待查方向**（按可能性排序）：

1. **`no_grad` 是否真的阻止了图构建**：本引擎的算子**无条件**写 `_parents=(self, other)`，
   `no_grad` 可能只影响 `_backward` 的挂载。若中间张量的 `_backward` 仍持有对上游的引用，
   而某个闭包又把它们串起来，清 `out._parents` 不足以断开。
2. **`bw` 闭包捕获了什么**：`bw` 里 `re = fn(*inputs)` 会把重算图挂在闭包里；
   若 `re` 的生命周期跨层延续，会保留整层激活。
3. **池的 live 计数口径**：`peak_live_bytes` 是否把"已 `__del__` 但未归还"的块也计入。
4. **视图/reshape 产生的 keepalive 链**：`permute`/`reshape` 在 CUDA 上是真拷贝，
   但 `keepalive` 可能把大缓冲挂在生命周期长的张量上。

## 4. 对 P100 用户的可行动结论

**当前版本（0.9.52）在 16 GB 上不能按原配置训练。** 临时可跑的配置（估算，需实测）：

| 配置 | 估算 |
| --- | --- |
| L=8，S=2048，B=1，dh=128 | 激活≈7 GiB + 参数/梯度/优化器 6.4 GiB ≈ **13.4 GiB**，可能刚好 |
| L=16，S=1024，B=1 | 单层激活约减半 ⇒ 更宽裕 |

**但这是绕过问题，不是解决问题。** 真正该做的是把检查点修到"峰值与层数无关"，
那时 20 层 / S=2048 / B=2 才有可能进 16 GB。

## 5. 修好之后的验收判据

1. 上表"检查点开"一列，L=2/4/8 的峰值差异 **≤0.2 GiB**（只剩残差流的线性部分）。
2. 开启后的峰值 **严格低于** 关闭时。
3. 数值与不开检查点**逐位一致**（现有测试已覆盖）。
4. P100 16GB 上，20 层 / d=1280 / FF=5120 / S=2048 / B=2 能跑通一步。
